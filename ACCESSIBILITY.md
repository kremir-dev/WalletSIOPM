# Accessibility Statement for WalletSIOPM

WalletSIOPM is committed to providing an accessible and inclusive personal finance management experience for all users, including individuals with disabilities or those utilizing screen readers and assistive technologies.

## Commitments and Standards

* **Material Design 3 Components:** The user interface strictly adheres to Android Material Design 3 specifications, ensuring that all interactive elements and touch targets meet or exceed recommended minimum dimensional thresholds for physical accessibility.
* **Screen Reader Compatibility:** Structural UI components and navigation pathways are engineered to provide definitive, contextually meaningful labels fully compatible with the Android TalkBack ecosystem.
* **Dynamic Theming:** The platform natively supports independent Dark and Light display modes to accommodate users with varying degrees of visual sensitivity and contrast requirements.

## Reporting Accessibility Issues

If you encounter an accessibility barrier or experience operational difficulties while interacting with any feature inside WalletSIOPM, please document the occurrence and contact us:

* **Email:** kremirdev@proton.me

To facilitate an efficient review, please include the following technical specifications in your report:
* A definitive description of the encountered barrier or interface limitation.
* The explicit Android API version and underlying hardware device model.
* The specific assistive technology deployed during the occurrence (e.g., TalkBack), if applicable.

All accessibility reports undergo prompt validation, and verified issues will be prioritized for remediation in subsequent application deployment cycles.
