# Security Policy

## Supported Versions

Currently supported versions with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.3.x   | :white_check_mark: |
| < 2.3.0 | :x:                |

## Platform Compatibility

- **Supported Android Versions:** Android 7.0 (API 24) – Android 16 (API 37)
- **Untested:** Android 17+

## Reporting a Vulnerability

If you discover a security vulnerability within WalletSIOPM, please do not open a public issue. Instead, report it directly via email:

* **Email:** kremirdev@proton.me

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Device / Android version details if applicable.

We will review the report and respond as soon as possible. Thank you for helping keep WalletSIOPM secure!
